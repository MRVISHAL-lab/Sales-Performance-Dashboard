# Sales Performance Dashboard | Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales, profitability, product categories, payment methods, regional performance, and customer segments.

## Key Performance Indicators (KPIs)
- **Total Sales:** 68.24M
- **Total Orders:** 1,000
- **Total Profit:** 12.76M
- **Total Quantity Sold:** 5,676
- **Profit Margin:** 18.70%

## Dashboard Features
- Regional Sales Analysis
- Sales Distribution by Payment Method
- Profit Contribution by Product Category
- Monthly Sales and Profit Trends
- Sales Performance by Product Category
- Sales and Discount Analysis by Customer Segment
- Interactive Filters for City, Segment, and Region

## Key Insights
- The South region recorded the highest sales at 14.6M.
- Electronics contributed approximately 73.48% of total profit.
- Electronics generated approximately 57M in sales.
- Debit Card was the leading payment method at 21.89%.
- The overall profit margin was 18.70%.
